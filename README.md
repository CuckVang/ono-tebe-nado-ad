# Оно тебе надо

Проектная работа 2 спринта курса «Фронтенд-разработчик» Яндекс Практикума.

Одностраничный сайт аукциона вещей, в которые никто не верил.

## Что использовано

- семантическая HTML-разметка (header, main, section, footer, nav, address);
- CSS Grid для шапки, секции «Об аукционе» и подвала;
- Flexbox для меню и карточек лотов;
- абсолютное позиционирование для полупрозрачного оверлея;
- подключение локальных шрифтов Raleway через @font-face.

Ссылка на репозиторий: https://github.com/CuckVang/ono-tebe-nado-ad
